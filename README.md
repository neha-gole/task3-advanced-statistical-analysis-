# Task 3 – Advanced Statistical Analysis & Hypothesis Testing

This project performs advanced statistical analysis and hypothesis testing using Python.

## Statistical Tests
- Shapiro-Wilk Test
- Kolmogorov-Smirnov Test
- Two-Sample t-test
- Mann-Whitney U Test
- One-Way ANOVA
- Two-Way ANOVA
- Tukey HSD Post-hoc Test

## Dataset
Superstore Sales Dataset

## Tools & Libraries

- Pandas
- NumPy
- SciPy
- Statsmodels
- Matplotlib
- Seaborn
